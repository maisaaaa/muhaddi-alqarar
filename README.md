# مُهدّئ القرار الفوري (Immediate Decision-Calm)
**فريق نبض الأمان — هاكاثون SCAMSHIELD AI**

## الفكرة
أداة ويب تفاعلية تعتمد على التدخل النفسي الفوري لكسر التوتر والاندفاع اللحظي أثناء محاولات الاحتيال الإلكتروني، عبر إدخال «وقفة قرار» وتنبيهات ذكية تساعد المستخدم على التفكير النقدي قبل اتخاذ أي إجراء أو تحويل مالي.

## أبرز مزايا النموذج الأولي (MVP)
- **وقفة القرار اللحظية:** إبطاء الاستجابة السريعة تحت الضغط النفسي أو التهديد الوهمي.
- **تشريح أساليب الاحتيال:** توضيح مؤشرات الخداع والاستعجال في الرسائل والسيناريوهات.
- **الخصوصية أولاً (Privacy-by-Design):** تصميم يراعي عدم تخزين بيانات حساسة أو تعقيدها.
